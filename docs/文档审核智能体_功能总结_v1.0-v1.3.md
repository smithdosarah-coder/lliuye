# X-Nexus 文档审核智能体

## 产品定位

企业级文档智能审核平台。基于大模型与可配置规则引擎，对企业核心业务文档进行自动化审核——合规风险、数据一致性、格式规范、财务准确性、签章完整性，一份 30 页合同 90 秒出结果。

审核准确率 98%+，同时处理 50 份文档不排队，已服务金融行业头部客户。

---

## 智能解析

拿到文档的第一步是"看懂它"。

- PDF 标准文档和扫描件都能处理，扫描件自动 OCR 提取全部文字、表格、印章、签名
- Word 文档（.doc / .docx）原生支持，保留完整格式结构
- Excel 表格数据提取与校验
- PPT 演示文稿内容审核
- 100 页以上大文档分段并行处理，不卡不丢
- 智能识别文档结构——章节、标题、正文、附件，为后续逐项审核打基础

## 多维审核能力

不限文档类型，按审核维度覆盖。同一份文档可以同时跑多个维度，结果合并输出。

### 合规性审核

检查文档内容是否符合法规政策和企业内部规范。识别敏感表述、禁用词、政治风险措辞、不当称谓。引用的外部链接自动验证有效性。

### 一致性校验

多份关联文档之间自动交叉比对——合同标的、金额、公司名称、法人信息、银行账户、签署日期，跨文档出现的同一数据必须一致，不一致的逐条标出。

单文档内部也查：正文里的数字和表格对不对得上，前后描述有没有矛盾。

### 格式规范

按企业预设模板检查排版：字体字号、行距段距、页眉页脚、章节编号、水印。模板可以自定义，换一家客户换一套标准。

### 财务数据

金额大小写是否一致，税金计算反推验证，分项金额加总是否等于合计。数字格式（千分位、小数点、单位）统一性检查。

### 语言质量

错别字、标点符号、语法问题、专业术语拼写。在正式文档里，一个"的地得"错误就可能影响客户对专业度的判断。

### 签章与授权

自动识别合同中的印章位置和内容，校验双方是否均已用章、章是否清晰可辨、印章名称和合同主体是否匹配。签字人如果是授权代表，自动校验授权委托书的有效性——范围、期限、人员是否对应。

## 审核报告

审核完不是丢一堆问题列表了事。

- 原文在线预览，问题直接高亮在文档里，按风险等级分色标注
- 点击任意问题，弹出详细说明：什么问题、风险等级、审核依据、修改建议
- 同一段落有多个问题的合并展示，不重复干扰
- 误报一键标记，标过的不再出现，导出时自动过滤
- 一键导出 Word 带批注可编辑文档——审核人员拿到就能直接改，不用对着 PDF 手动誊抄
- 审核报告包含：文档基本信息、总耗时、问题总数与分级统计、逐条问题详情、规则引用

## 管理后台

给管理者用的，不是给审核员用的。

**数据看板**：系统运行状态、审核效果指标、问题分布趋势——管理层打开就能看到这套系统到底省了多少人力。

**规则管理**：业务专家自己维护审核规则，不用找技术改代码。规则的增删改查、启用停用、版本管理全在界面上操作。

**场景管理**：不同业务线、不同文档类型可以配置不同的审核场景，各场景独立规则集，互不干扰。

**用户权限**：登录认证、角色区分（审核员 / 管理员 / 只读）、数据隔离——每个用户只能看到自己权限范围内的文档和结果。

## 安全与部署

- 传输加密（TLS）、存储加密（AES-256）
- 基于角色的访问控制，所有操作留审计日志
- 用户数据严格隔离，跨用户不可见
- 支持私有化部署，数据不出客户网络

## 产品路线图

已上线的能力覆盖了企业文档审核的核心场景。接下来重点扩展三个方向：

**更多文档格式**：大文档（100 页+）分段审核优化、多语种文档支持。

**更深的业务集成**：与企业 OA / 合同管理系统对接，审核请求和结果双向流转，嵌入现有业务流程不改变用户习惯。

**更智能的审核**：版本对比——同一文档的草稿和终稿自动比对，识别实质性修改（条款变动、金额调整），不是简单的文字 diff。
