## 部署所需 env 与 seed 步骤

部署前确认生产服务器具有施工卡引用的 DP002 材料、`samples/经纬测绘_对公成稿A.docx`、`outputs/v16_llm_classified.json` 及有效 `DEEPSEEK_API_KEY`。

1. 后端运行环境设置：

   ```dotenv
   DEMO_FORM_MODE=1
   DEEPSEEK_API_KEY=<existing-production-secret>
   ```

2. 在仓库根目录执行一次真实 seed：

   ```powershell
   py -3 scripts/seed_demo_form_session.py
   ```

   预期输出包含：

   ```text
   SEEDED ...\outputs\demo-form\report-default-session.json
   company=蓝汀家电连锁（浙江）有限公司 materials=7 sections=<非零>
   ```

3. 前端必须在构建时设置（不是仅在启动时设置）：

   ```powershell
   $env:NEXT_PUBLIC_DEMO_FORM_MODE='1'
   pnpm build
   ```

4. 重启后端并启动新前端构建，然后验证：

   - GET `/api/report/demo/default` 为 200，profile 为蓝汀、materials=7、sections 非空。
   - POST `/api/report/demo/run` 为 403，message 为指定形态说明。
   - 无缓存冷启动打开 `/archive/report`，检查蓝汀、对公成稿 A、真实章节流、7 材料、QC 两项 raw/threshold。
   - 从页面导出 DOCX/PDF，解包/提取文本核对“鼎盛”0、蓝汀至少 1、信用代码正确、日期与上海本地同日。
   - 打开 `/today`、`/warroom`、`/audit` 做最终公网视觉验收。

关闭形态模式时，将两个开关都设为 `0`，重新构建前端并重启后端；仅修改后端运行时变量不会改变已构建的前端界面。
