## 1. 开场（1 min）：业务痛点

> "风险经理 1 个月扫一遍在贷客户池 · 漏一个红灯 = 一笔不良。
>
> 传统方式：手工查工商 / 查司法 / 翻流水 · 100 家客户 1 周。
>
> Agent4 把'扫描 + 交叉 + 分级'压到 30 分钟：
> - 外部信号（工商 / 司法 / 经营异常 / 行政处罚）实时扫
> - 内部信号（流水异动 / 大额支取 / 跨省高频）跨源比对
> - 红 / 黄 / 绿 三档分级 + 处置建议
>
> 这不替代风险经理 · 是把'体力活'压到'AI 起手 + 人工核'。"

## 2. Demo 一步一步（8 min）

### Step 1：上传客户池 + 配置规则库（1 min）

打开 `http://localhost:3000/archive/alert`。
- 客户池：上传在贷客户 csv（含客户 ID + 工商 + 内部交易摘要）
- 规则库：选择启用规则集（`agent4_alert.yaml` 8 条 reason_codes 配套）
- 时间窗：30 / 60 / 90 天 三选一

> 💬 讲稿："时间窗影响信号灵敏度——30 天最敏感（误报多）· 90 天最稳（漏报多）。建议 60 天。"

### Step 2：触发双路扫描（2 min）

点"开始扫描"· SSE 5 阶段：
1. `load_pool` 客户池加载
2. `external_scan` 外部信号扫描（工商 / 司法 / 经营异常 / 行政处罚）
3. `internal_scan` 内部交易扫描（流水异动 / 大额支取 / 跨省高频）
4. `cross_join` 双路交叉（外部 + 内部叠加）
5. `tier_classify` 红 / 黄 / 绿分级

实时进度条 · 100 家客户 · 真模式 ~8-10 min · Mock 模式 ~3 秒。

> 💬 讲稿："双路交叉是 Agent4 核心——单源信号容易误报 · 双路叠加触发的红灯精准率 ≥ 80%。"

### Step 3：看红 / 黄 / 绿盘（2 min）

右侧产出区：
- **红灯客户榜**（立即处置）：双路叠加 / 硬红线触发（如经营异常 / 大额支取异常）
- **黄灯客户榜**（复核跟进）：单路告警 / 软告警（如工商变更 / 流水异动）
- **绿灯客户**（正常）：无信号
- **每客户**：信号摘要 + 信号时间线 + Top-N reason_codes（对照 `agent4_alert.yaml` 8 条字典）

点任一红灯客户 → 详情页：
- 外部信号（裁判文书网链接 + 公示系统截图）
- 内部信号（流水异动统计图 + 大额支取记录）
- Agent4 处置建议

> 💬 讲稿："每个红灯都能 30 秒追到原始信号 · 风险经理上会前已经知道为什么红。"

### Step 4：处置建议 + 导出台账（1.5 min）

- **处置建议**：电话回访 / 现场尽调 / 提前到期 / 收贷 / 报告监管 5 档
- **升级路径**：L1 客户经理回访（≤ 4h）/ L2 风险经理介入（≤ 1 工作日）/ L3 资产保全 + 法务（仅 P1）
- "导出预警台账 xlsx" → 含红/黄客户全列 + 信号摘要 + 处置建议 + 时间线

### Step 5：跨域协同（1 min）

- 红灯客户 → 自动触发 Agent5 合规复查（如客户被列入失信被执行）
- 红灯客户 → 自动触发 Agent3 重新评分（更新风险等级）
- 反馈飞轮：风险经理标"误报"→ `/api/feedback` 写 jsonl · 后续扫描调阈值

> 💬 讲稿："Agent4 不是终点 · 是贷后管理的起点。"

### Step 6：合规与隐私（0.5 min）

- 客户内部数据本地处理 · 不出境
- 仅 SearchProvider 检索词出境（公开信息 · 工商 / 司法 / 经营异常）
- 审计日志 `data/audit/*.jsonl` 留痕

## 3. 合规与监管锚点（1 min）

| 监管 | Agent4 实现 |
|---|---|
| 商业银行互联网贷款管理暂行办法 2025 | 自主风控 · 不替代银行内部资产保全 SOP |
| 数据安全法 + 个保法 | 客户内部数据本地处理 · 详见 `docs/compliance/data-localization.md` |
| 反洗钱法 | 大额支取异常 → STR/SAR 流程触发（如适用） |
| CAC AI 治理 2.0 | reason_codes 字典 + 模型卡 |

## 4. 典型 Q&A（2 min）

- **Q**：误报怎么管？
  **A**：误报率 ≤ 15% 是目标基线（对标同盾诸葛 -45% 优化基线）。风险经理标 false positive 回流 · 后续扫描自动调阈值。

- **Q**：客户内部数据出境吗？
  **A**：不出。所有内部交易数据本地处理 · 仅外部信号查询关键词（公开信息）经境内 SearchProvider endpoint。

- **Q**：扫描多久一次？
  **A**：建议 30 天 + 7 天 双频率（30 天全量 + 7 天增量）。也支持事件驱动（如政策发布触发）。

- **Q**：上线工期？
  **A**：Demo 1 周 · POC 3 周（含客户内部交易接入）· 生产 6-8 周（含信创适配 + 内部系统对接）。
