## 1. 产品定位

基于企业画像和行业资讯的全渠道融资匹配引擎，为银行客户经理提供"一键输入企业信息、自动输出渠道推荐方案"的智能获客决策支持。

---

## 2. Demo目标

### 2.1 目标受众与证明目标

| 受众 | 关注点 | Demo需要证明什么 |
|------|--------|-----------------|
| 银行数字化转型负责人 | 获客效率提升、ROI | 系统从企业画像到渠道推荐全流程 < 30秒，替代人工数小时的渠道筛选工作 |
| 银行对公/普惠业务部门 | 推荐准确性、渠道覆盖度 | 5大类13个子渠道全覆盖，评分模型可解释、推荐结果符合业务直觉 |
| 技术评审方 | 架构合理性、可扩展性 | Agent协议标准化、规则可配置、评分模型可插拔、与其他Agent数据互通 |
| 合作伙伴/投资方 | 产品成熟度、商业化路径 | 前端专业度达到可交付水准，不是"技术原型"而是"产品Demo" |

### 2.2 核心论点

1. **精准匹配**：5维加权评分模型(行业30%/规模25%/地域20%/政策15%/历史10%)实现可解释的渠道推荐
2. **资讯增强**：联网搜索行业动态和政策窗口，使推荐具有时效性
3. **开箱即用**：20家预置企业，选择即匹配，零输入成本
4. **矩阵协同**：推荐结果可直接传递给Agent2(信贷报告生成助手)，实现"获客->尽调"链路

### 2.3 Demo成功标准

- 全流程演示 < 3分钟（含讲解）
- 零配置启动（无需输入API Key、选模型）
- 4个预置场景100%跑通，推荐结果符合业务逻辑
- 可导出PDF报告

### 4.3 组件详细设计

#### 4.3.1 预置场景快选区

- 4张场景卡片，2x2网格布局
- 每张卡片含：场景名称、行业图标、地区标签
- 点击效果：卡片高亮选中 -> 表单自动填入 -> 自动触发匹配
- 右上角"自定义"按钮，清空表单回到手动输入模式

#### 4.3.2 企业信息表单

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 企业名称 | 文本输入 | 否 | 支持从预置企业库下拉选择 |
| 行业 | 下拉选择 | 是 | 31个行业选项 + 自定义输入 |
| 地区 | 文本输入 | 否 | 支持省/市/区三级 |
| 企业规模 | 下拉选择 | 否 | 大型/中型/小型/微型 |
| 年营收 | 文本输入 | 否 | 如：4800万、1.2亿 |
| 员工人数 | 数字输入 | 否 | |
| 关键词 | 文本输入 | 否 | 逗号分隔，如"专精特新,高新技术" |
| 企业性质 | 下拉选择 | 否 | 国有/民营/外资/混合 |
| 补充描述 | 多行文本 | 否 | 自由文本，LLM提取补充信息 |

### 7.4 容错设计

| LLM返回格式错误 | llm_json() 内置3次重试+JSON提取正则 |
