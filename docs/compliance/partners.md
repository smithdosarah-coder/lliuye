# Agent6 合作机构清单 · Third-Party Services Register

**版本**：v1.0
**更新日期**：2026-04-19
**对应 DoD**：L2-13（合作机构清单 + 数据分类 + 境内/境外标签）
**合规依据**：金管总局《助贷新规》2025-10 合作机构备案强制；《金融机构数据安全管理办法》+ 93 号文。

---

## 1. 为什么要维护这份清单

2025-10 金管总局《关于加强商业银行互联网助贷业务管理的通知》把**合作机构备案**从"指导性"升级为"强制性"：总行必须建动态合作机构名录，对外引入的第三方服务需按"数据类型 / 合规依据 / 是否涉境外 / 降级策略"逐项备案。违规后果：罚款（百万至千万）→ 暂停业务资质 → 吊销。

本文件为 Agent6 的备案材料底稿，可直接并入银行合规部的合作机构名录申报流程。Agent6 自身不直连客户真实数据到境外 API，所有客户材料（企业报表 / 身份证 / 授信记录）均**本地处理**；以下列出的是 Agent6 pipeline 在"知识库/行业信号/宏观数据"层可能触达的外部服务。

## 2. 清单（按 `shared/sources/` 分层架构登记）

### 2.1 概览表

| # | 服务 | 域名 | 数据类型 | 境内/境外 | 合规依据 | 是否触达客户真实数据 | 降级策略 |
|---|---|---|---|---|---|---|---|
| 1 | Tavily Search | tavily.com | 公开互联网检索结果（行业新闻 / 政策解读 / 企业公开信息） | 境外（美国） | 服务条款公开，仅用公开信息检索 | **否**（仅用公开关键词，不传客户材料） | 切 Mock / 切 gov_cn / 整段 section 标"未能自动填写" |
| 2 | DeepSeek Chat | api.deepseek.com | LLM 推理（system + user prompt） | **境内** | 《生成式人工智能服务管理办法》2023-08 已备案 | 是（report 生成阶段 prompt 含企业画像摘要） | 切 stub（返回空串，下游按"未能自动填写"走 QC） |
| 3 | akshare | akshare 官方 API | 金融市场公开数据（股票 / 行业指数 / 宏观指标） | 境内 | 开源库，走公开数据接口 | 否 | 离线行业卡兜底 |
| 4 | gov.cn | gov.cn | 政府公告 / 政策文本（国务院 / 部委网站） | 境内 | 公开政府信息，无合规障碍 | 否 | 切离线政策快照 |
| 5 | pbc.gov.cn | pbc.gov.cn | 人民银行公告 / 货币政策 / 征信制度 | 境内 | 公开央行信息 | 否 | 切离线政策快照 |
| 6 | flk.npc.gov.cn | flk.npc.gov.cn | 国家法律法规数据库（全国人大） | 境内 | 公开法律文本 | 否 | 切离线法条快照 |

### 2.2 分层（对应 `shared/sources/`）

- **Tier 1 · 宏观/行业源**：`akshare` / `gov_cn` / `pbc_gov` / `flk_npc`
  - 全部境内、公开、无客户数据触达
  - 用途：行业卡片 / 政策引用 / 监管条款
- **Tier 2 · 通用搜索源**：`tavily`
  - 境外但不触客户数据；默认降级顺位最低
  - 用途：补充行业新闻 / 竞品动态
- **Tier 3 · LLM 推理**：DeepSeek Chat
  - 境内已备案；prompt 含企业画像摘要（客户授权材料加工后产物）
  - 用途：Evidence-First 三阶段生成

### 2.3 写在代码里的抽象

- 源实现位于 `shared/sources/impls/`（5 个），通过 `shared/sources/base.py` 的 `BaseSource` 协议暴露
- 路由器 `shared/sources/router.py` + 降级器 `shared/sources/degrader.py` 按偏好链选源
- 各 Agent 域独立配置偏好链：`agent_*/sources_config.py`
- 冒烟测试：`test_sources_smoke.py`

切换/禁用任一源仅需在偏好链中摘除，代码无硬编码 if-else 判断（CLAUDE.md §3.4）。

## 3. 数据流向约束（硬禁区）

以下场景**禁止**任何境外 API 触达：

1. 客户材料（营业执照 PDF / 财务报表 xlsx / 征信报告 PDF / 身份证件）—— 仅本地 `material_kb.py` + `financial_analyzer.py` 处理
2. 企业画像中的财务数字（营收 / 利润 / 资产 / 现金流）—— 仅传入 LLM prompt 的**摘要文本**（DeepSeek 境内）
3. 个人信息（法人 / 实控人姓名 / 身份证号 / 家庭住址）—— 仅驻内存 EnterpriseProfile，不入任何搜索/LLM 外调
4. 审贷员反馈 `data/feedback/*.jsonl`—— 本地文件，不回传任何外部服务

境外源（Tavily）的调用参数仅能包含**公开关键词**（行业名 / 政策名 / 公开企业名）。由 Agent 域配置 `sources_config.py` 显式声明 Tavily 可见字段，禁止 leak EnterpriseProfile 结构。

## 4. 备案材料清单（对接银行合规部）

每个合作机构需补充以下材料（由合规部统一向监管报备）：

- [ ] 服务合同 / 服务条款副本
- [ ] 数据处理协议（DPA）
- [ ] 服务商等保认证证书（境内服务必备）
- [ ] 过境评估备案回执（仅 Tavily，若需要启用）
- [ ] 年度安全审计报告（境内服务需附）
- [ ] SLA 承诺书

## 5. 动态维护

| 事件 | 响应 |
|---|---|
| 新增源实现（`shared/sources/impls/` 新文件） | 必须同步更新本文件 §2.1 + §2.2 |
| 源接口变更 / 域名变更 | 更新本文件 + 评估是否需要重新备案 |
| 监管新规发布 | 对照 §4 清单，由合规部触发复核 |
| 境内服务转境外（如服务商迁移） | **立即停用** + 触发红线事件 |

## 6. 审计链

- 每次对外调用由 `data/audit/YYYY-MM-DD.jsonl` 记录（DoD L2-12）
- 调用失败触发降级链（`shared/sources/degrader.py`）
- 审计日志仅落 `input_hash`，不落 prompt / 材料原文
