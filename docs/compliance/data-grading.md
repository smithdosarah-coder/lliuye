# Agent6 数据分级 · Data Classification

**版本**：v1.0
**更新日期**：2026-04-19
**对应 DoD**：L2-14（每字段 / 外部源标一般 / 重要 / 核心；核心数据禁止出境）
**合规依据**：《金融机构数据安全管理办法》+ 金管总局 93 号文；《数据安全法》《个人信息保护法》。

---

## 1. 分级标准

依据金管总局 93 号文《银行业金融机构数据分级指引》，三级分级体系：

| 级别 | 定义 | 典型 | 处理约束 |
|---|---|---|---|
| **核心** | 一旦泄露危及金融稳定或国家安全 | 大额集中信贷敞口 / 系统性大户内部评级 | **禁止出境**、禁入任何外部 API、最小化访问、本地加密 |
| **重要** | 涉及经营安全或重大客户利益 | 客户财务报表 / 征信明细 / 授信决策记录 | 本地处理、仅境内 API、授权访问、保留期 ≥ 5 年 |
| **一般** | 公开或低敏信息 | 行业新闻 / 政策条款 / 公开工商信息 | 允许境外公开检索，无特殊约束 |

## 3. 访问控制矩阵

| 角色 | 一般 | 重要 | 核心 |
|---|---|---|---|
| 客户经理（报告发起方） | 读写 | 读（本人 session） | 读（本人 session）|
| 审贷员 | 读写 | 读写（流转中案件） | 读（流转中案件）|
| 合规官 / 审计员 | 读 | 读（需脱敏） | 读（需脱敏 + 二次授权） |
| 开发 / 测试 | 读 | 读（脱敏样本） | **禁**（仅 mock fixture） |
| 第三方服务商 | 公开字段 | **禁** | **禁** |

## 4. 销毁机制

- **session 级**（核心材料）：30 分钟 TTL，`_cleanup_expired_sessions` 惰性清理 `outputs/sessions/`
- **审计日志**（重要）：按日切分，独立合规备份流水；保留期后归档 / 销毁
- **反馈日志**（重要）：纳入数据飞轮消费后按需归档，脱敏样本可入模型卡附录
- **泄露响应**：一旦核心 / 重要数据流入未授权路径，24h 内触发根因分析 + 事故复盘

## 5. 出境评估清单

境外路径（当前仅 Tavily）调用前必须满足：

- [ ] 参数字段全部属于 **一般** 级
- [ ] `sources_config.py` 中显式声明允许字段，禁止透传 `EnterpriseProfile.model_dump()`
- [ ] 调用进 `data/audit/*.jsonl`，含 endpoint + input_hash
- [ ] 调用失败走降级链（`shared/sources/degrader.py`），不阻塞报告生成

## 6. 红线（触发停工）

- 重要 / 核心数据进 git
- 重要 / 核心数据传境外 API
- 审计日志被篡改 / 格式变动（走 Q-NNN 先议）
- `data/feedback/*.jsonl` schema 变动不兼容
