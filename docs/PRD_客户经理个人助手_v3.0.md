# PRD：客户经理个人助手 v3.0

**版本**：v3.0（Demo改造版）
**日期**：2026-04-13
**作者**：刘野
**文档性质**：产品需求文档（面向Demo交付 + 平台适配）

---

## 1. 产品定位

客户经理个人助手是一套部署在众安信科AI中台上的多Agent系统，整合6个专业子Agent，覆盖银行信贷业务从获客、授信、风控到合规的全链条。

**v3.0核心变化**：从"6个独立技术原型"升级为"1个统一入口的可演示产品矩阵"。

---

## 2. 版本演进

| 版本 | 时间 | 里程碑 |
|------|------|--------|
| v1.0 | 2026-03-23 | 报告生成助手MVP启动 |
| v2.0 | 2026-04-09 | 报告生成助手五项架构改造完成 |
| v2.1 | 2026-04-09 | 5个Agent方向确定，规划文档输出 |
| **v3.0** | **2026-04-13** | **5个Agent代码原型已完成，进入Demo改造阶段** |

### v3.0改造背景

5个Agent的后端业务逻辑已由AI辅助编码完成（约200KB代码），但存在以下问题：
- 前端5个页面UI完全相同（Gradio默认chatbot），无品牌感和视觉差异
- 没有预置演示数据，需要用户自行填写API Key、上传文件
- 没有统一入口（Portal），5个Agent各跑独立端口
- Agent间数据流（EnterpriseProfile）设计了但未接通
- 无报告导出功能

**改造原则**：后端留，前端扔，Demo层从零建。

## 3. 产品架构

### 3.1 四层架构

```
┌─────────────────────────────────────────────────┐
│ 用户界面层：Portal统一入口 + 各Agent差异化页面       │
├─────────────────────────────────────────────────┤
│ 编排层：主Agent（意图路由）+ 6个子Agent              │
├─────────────────────────────────────────────────┤
│ 业务逻辑层：规则引擎 / 评分模型 / 分析流水线          │
├─────────────────────────────────────────────────┤
│ 共享数据层：EnterpriseProfile + 知识库 + Mock数据    │
└─────────────────────────────────────────────────┘
```

### 3.2 六大子Agent

| # | Agent名称 | 业务环节 | 核心能力 | 代码状态 | Demo状态 |
|---|----------|---------|---------|---------|---------|
| 1 | 全渠道流量匹配 | 贷前/获客 | 多渠道线索识别 + 产品匹配 + 营销建议 | ✅ 后端完成 | ❌ 需改造 |
| 2 | 风控策略运营 | 贷中/风控 | 自然语言→规则DSL + 回测 + 差错分析 | ✅ 后端完成 | ❌ 需改造 |
| 3 | 授信决策辅助 | 贷中/审批 | 读取报告→风险评估 + 额度建议 | 🔄 需重写 | ❌ 需改造 |
| 4 | 贷中风险预警 | 贷后/监控 | 规则+LLM双通道预警 + 处置建议 | ✅ 后端完成 | ❌ 需改造 |
| 5 | 合规巡检 | 全流程 | 政策解析 + 逐条合规比对 + 缺陷分级 | ✅ 后端完成 | ❌ 需改造 |
| 6 | 报告生成助手 | 贷前/尽调 | 自动生成授信调查报告 | ✅ 核心引擎成熟 | ✅ 可演示 |

### 3.3 Agent间数据流

```
全渠道流量匹配 ──推荐客户──→ 报告生成助手 ──企业画像JSON──→ 授信决策辅助
                                  │                         │
                                  │──财务锚点──→ 风控策略运营  │──风险标签──→ 贷中风险预警
                                  │                                        │
                                  └──────────────── 合规巡检 ←←←←←←←←←←←←┘
```

**关键数据对象**：

| 数据对象 | 生产者 | 消费者 | 格式 |
|---------|-------|-------|------|
| EnterpriseProfile JSON | 报告生成助手 | 所有Agent | Pydantic模型，40+字段 |
| 财务锚点 | 报告生成助手 | 授信决策辅助、风控策略运营 | 结构化数值（资产/负债/营收等） |
| 风险标签集 | 授信决策辅助 | 风控策略运营、贷中预警 | 枚举标签列表 |
| 合规状态 | 合规巡检 | 所有Agent | 通过/未通过 + 明细 |

## 4. Portal统一入口

### 4.1 设计原则

- **一个入口**：不再是5个独立端口，而是1个Portal应用
- **品牌统一**：众安信科品牌色（#1677FF蓝）+ 统一Header
- **页面差异**：每个Agent Tab有独立布局，不共用模板
- **配置隐藏**：API Key在Settings抽屉统一配置，不暴露在Agent页面

### 4.2 页面结构

```
┌──────────────────────────────────────────────────────────┐
│  ⚡ 众安信科 · 信贷AI智能体矩阵              [⚙ Settings]  │
├──────────────────────────────────────────────────────────┤
│  [获客匹配] [风控策略] [授信决策] [贷中预警] [合规巡检]      │
├──────────────────────────────────────────────────────────┤
│                                                          │
│   ┌──────────────────────────────────────────────┐      │
│   │                                              │      │
│   │         各Agent差异化内容区                    │      │
│   │         (布局、组件各不相同)                    │      │
│   │                                              │      │
│   └──────────────────────────────────────────────┘      │
│                                                          │
└──────────────────────────────────────────────────────────┘
```

### 4.3 各Tab布局预览

## 6. 技术架构

| 模块 | 文件 | 职责 |

| BaseAgent | `shared/base_agent.py` | 事件协议（thinking/message/tool_call/tool_result/file/done）+ LLM封装 |
