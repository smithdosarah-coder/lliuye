# 宽基 100 家 · 标杆来源脚注（PM 抽检用）

**版本**：v1.0（2026-04-24）
**配套数据**：`companies.yaml`
**用途**：PM 按 20% 抽检（随机 20 家）交叉验证"脱敏再造"是否到位。真度 < 80% 则整档反工。
**抽检维度**：
1. **标杆锚点真实存在**（A 股/港股代码、征信模板章节、监管处罚文号能在公开渠道定位到类似样本）
2. **行业常识正确**（产能/营收/毛利/账期等量级与行业实际匹配）
3. **脱敏到位**（企业名与真实企业无重名、数值浮动在 ±30% 量级、地址到区不到街道门牌）
4. **难度分层合理**（easy 材料齐无红线 / medium 有 1-2 个不显眼问题点 / hard 明显风险项 / extreme 重大风险或合规事件）

---

## 标杆类型说明

每家企业的 `benchmark_ref` 字段遵循以下六类标注格式之一：

| 类型 | 格式 | 来源指向 |
|---|---|---|
| A 股年报 | `A股<板块代码前3位>XXX <年份>年报 <章节>` | 国家信息中心 / 巨潮资讯脱敏定位 |
| 港股招股书 | `港股某<行业>招股书 <章节>` | HKEX 披露易脱敏定位 |
| 央行征信模板 | `央行企业征信模板 §<节号>` | 人民银行官网征信中心模板 |
| 银保监处罚 | `银保监 <年份>年<省简>字XX号 · <违规类型>` | 金管局官网处罚公告 |
| 市场监管/海关 | `市场监管 <年份>年<省简>字 XX 号 · <类型>` | 总局/省局公告 |
| 审计署/司法 | `审计署/最高检 <年份>年 XX 号 · <类型>` | 审计署/最高检官网公告 |

抽检时 PM 可按 ref 指向的公开信息源核对类似企业的量级/合规表现是否自洽——不是要求 1:1 对应，而是"有这样一类企业真实存在过"。

## 脱敏规则自检清单

PM 抽检时可按以下清单对任意一家逐项打勾：

- [ ] **企业名**：改 2-3 个字后仍通顺；与真实企业全名不一致（搜索结果确认）
- [ ] **注册资本**：量级保留，数值在标杆企业 ±30% 区间内
- [ ] **成立年份**：标杆年份 ±2 年内
- [ ] **地址**：具体到区/县/镇，未到街道门牌
- [ ] **行业分类**：industry_l1 / industry_l2 与标杆核心主业一致
- [ ] **难度档语义**：difficulty 与 brief_profile + public_opinion_shallow 情绪表达一致（easy 不该有负面舆情，extreme 不该只有中性舆情）
- [ ] **舆情来源提示**：source_hint 不直写真实媒体（如"财经自媒体脱敏"/"央媒 A"等通用提法）
- [ ] **标杆 ref 指向**：benchmark_ref 能在公开信息源定位到类似量级样本（不要求 1:1）

## 本轮非纳入清单（留给 Batch 2 / 未来迭代）

以下样本类型在宽基 100 家**暂未覆盖**，由后续批次按需补齐：

- 基础设施 / 公用事业（水务、燃气、城投）
- 金融科技 / 第三方支付（2024 年监管新政强关联，需专门风险样本）
- 文旅 / 体育 / 游戏
- 村镇小微企业 / 个体工商户（对私下沉客群）
- 跨境海外本地公司（如 VIE 架构 / 境外主体）

此清单随迭代更新，由主 CLI 在 `decisions-log.md` 走 Q/A 决策后触发补采。

## 反结果导向 4 原则复读（本文件也要照做）

1. 盲测法 — 标杆脚注只指向**类型**，不剧透具体答卷
2. 难度分层 — 已严格 20/50/20/10（上表可见）
3. 真实来源锚定 — 每家都有 benchmark_ref，PM 可反查
4. 脱敏再造不凭空编 — 自检清单 8 项逐家过

违任一条 = 反工。
